# Семейный календарь Sayan

Локальная адаптивная веб-страница для планирования недели: смены, занятия, личные и семейные события.

## Запуск локально

Откройте `index.html` в браузере. События сохраняются в локальном хранилище браузера.

Страница не использует библиотеки, сборку или серверные функции; подходит для GitHub Pages.
